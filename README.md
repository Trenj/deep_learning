# deep_learning

Практическая работа 1

Написать компьютерную программу на языке Python 3 создающую и обучающую нейронную сеть для распознавания рукописных цифр с использованием метода градиентного спуска и базы данных MNIST.

Исходные данные:

Количество слоев нейронной сети: 3.
Входные данные для нейронной сети: изображения размером 28x28 пикселов.
Среда программирования: Python 3.6 и выше.
Используемая библиотека: NumPy.
Рабочая ссылка на файл mnist.pkl.gz:

https://figshare.com/articles/dataset/mnist_pkl_gz/13303457?file=25635053

Параметры сети и обучения (папка practical-1, значения по методичке и task.txt):

Архитектура: 784 входа, 30 нейронов скрытого слоя, 10 выходов.
Функция активации: сигмоида.
Функция потерь: квадратичная (среднеквадратичная ошибка).
Обучение: стохастический градиентный спуск, 30 эпох, мини-пакет 10, скорость обучения 3.0.
Данные: 50000 пар для обучения, 10000 для проверки, 10000 для теста. Входы нормированы к диапазону от 0 до 1. Метки обучения закодированы вектором длины 10.

Как запустить (из папки practical-1):

python3 -c "import mnist_loader; training_data, validation_data, test_data = mnist_loader.load_data_wrapper(); import network; net = network.Network([784, 30, 10]); net.SGD(training_data, 30, 10, 3.0, test_data=test_data)"

После каждой эпохи выводится точность на тестовой выборке в виде Epoch N: верно / 10000.

Результат контрольного запуска за 30 эпох: на нулевой эпохе 9022 из 10000, лучший результат 9488 из 10000 на эпохе 26, на последней эпохе 29 получено 9477 из 10000. Точные числа зависят от случайной инициализации весов и могут отличаться при повторном запуске.

Состав папки practical-1: network.py (сеть и обучение), mnist_loader.py (загрузка MNIST), mnist.pkl.gz (данные), task.txt (условие и команда запуска), report.pdf (отчет со скриншотом), photo_2026-10-02_19-21-33.jpg (скриншот хода работы), Методические указания к практической работе 1.pdf (методичка).

Практическая работа 2

Составить мини-отчет на тему «Качество распознавания и скорость обучения нейронной сети»: выяснить, как на обучение влияют параметры метода обучения (скорость обучения, размер мини-пакета, число эпох) и топология сети, а затем проверить предположения экспериментально на программе из практической работы 1.

В practical-2 проведено 15 конфигураций сети (T1–T15) с разной топологией и параметрами обучения, для части запусков зафиксировано зерно ГСЧ, замерено время обучения и построено распределение предсказаний по цифрам.

Как запустить (из папки practical-2):

python3 -u run_tests.py [T1 T2 ...] [--seed N] [--repeats K]

Без аргументов выполняются все тесты; можно перечислить только нужные (например, T1 T10 T15). Параметр --seed задает начальное зерно для воспроизводимости, --repeats K повторяет каждый выбранный тест K раз.

Проверка насыщения сигмоиды при инициализации (без обучения):

python3 check_init.py

Основные результаты (полные логи — в results.txt и logs/):

Лучший результат — 9811 из 10000 (98.11%) у сети [784, 100, 10] с масштабированной инициализацией весов (w / sqrt(fan-in)), скорость обучения 3.0, seed 0 (тест T15).
Базовая сеть [784, 30, 10] при скорости 3.0 показывает около 95.4–95.6% (тесты T1 с seed 0 и 1), сеть [784, 50, 10] — 9579 из 10000 (95.79%), сеть [784, 15, 10] — 9353 из 10000 (93.53%).
Однослойная сеть [784, 10] заметно хуже: 8382 из 10000 (83.82%) при скорости 3.0 и 7511 из 10000 (75.11%) при скорости 1.0 — скрытый слой необходим.
Сеть [784, 100, 10] со стандартной инициализацией randn при скорости 3.0 дает лишь 8741–8694 из 10000: из-за большого fan-in сигмоида насыщается. check_init.py показывает, что до обучения предсказания схлопываются в одну-две цифры; масштабированная инициализация это исправляет (T15).
Слишком большая скорость обучения (100.0) и слишком маленькая (0.001 при пакете 1000) ухудшают результат; лучшие значения — примерно 0.5–3.0 при мини-пакете 10.

Состав папки practical-2: network.py (сеть и обучение из практической работы 1), mnist_loader.py (загрузка MNIST), mnist.pkl.gz (данные), run_tests.py (прогон тестов T1–T15), check_init.py (проверка насыщения сигмоиды), results.txt (сводный лог), logs/ (логи отдельных прогонов), report.docx (отчет), task.txt (условие).

Практическая работа 3

Написать компьютерную программу на языке Python 3 создающую и обучающую нейронную сеть для распознавания рукописных цифр с использованием метода градиентного спуска и стоимостной функции на основе перекрестной энтропии.

Параметры сети и обучения (папка practical-3, значения по методичке и task.txt):

Архитектура: 784 входа, 30 нейронов скрытого слоя, 10 выходов.
Функция активации: сигмоида.
Функция потерь: перекрестная энтропия (класс CrossEntropyCost; квадратичная функция сохранена в классе QuadraticCost).
Улучшенная инициализация весов: случайные значения делятся на корень из числа входов нейрона (метод default_weight_initializer; старый способ сохранен в методе large_weight_initializer).
Обучение: стохастический градиентный спуск с L2-регуляризацией, 30 эпох, мини-пакет 10, скорость обучения 0.5, параметр сглаживания lmbda = 5.0, оценочная выборка — validation_data, включен мониторинг стоимости и точности на обучающей и оценочной выборках.
Обученная сеть сохраняется в файл trained_network.json (метод save), загружается из файла методом load.

Как запустить (из папки practical-3):

python3 -u run_training.py [--seed N]

или вручную:

python3 -c "import mnist_loader; training_data, validation_data, test_data = mnist_loader.load_data_wrapper(); import network2; net = network2.Network([784, 30, 10], cost=network2.CrossEntropyCost); net.SGD(training_data, 30, 10, 0.5, lmbda=5.0, evaluation_data=validation_data, monitor_evaluation_accuracy=True, monitor_evaluation_cost=True, monitor_training_accuracy=True, monitor_training_cost=True); net.save('trained_network.json')"

Отчет по работе находится в файле report.docx.

Результат контрольного запуска (seed 42) за 30 эпох: на нулевой эпохе 9419 из 10000 на оценочной выборке, лучший результат 9645 из 10000 (96.45%) на эпохе 27, на последней эпохе 29 получено 9529 из 10000. Загруженная из файла trained_network.json сеть распознала 9464 из 10000 изображений тестовой выборки (94.64%). Время обучения около 6.3 минуты. Точные числа зависят от случайной инициализации весов и могут отличаться при повторном запуске.

Состав папки practical-3: network2.py (сеть с перекрестной энтропией, регуляризацией, улучшенной инициализацией и методами save/load), mnist_loader.py (загрузка MNIST), mnist.pkl.gz (данные), run_training.py (обучение, сохранение сети и проверка загрузки), results.txt (полный лог обучения), trained_network.json (обученная сеть), report.docx (отчет), task.txt (условие), Методические указания к заданию 3.docx (методичка).

Практическая работа 4

Применение специализированных библиотек: распознавание рукописных цифр с помощью Keras в среде Google Colab. В блокноте последовательно разобраны загрузка MNIST, подготовка данных, построение и обучение сети, оценка качества, построение графика точности и распознавание как изображения из тестовой выборки, так и собственной рукописной цифры, загруженной с Google-диска.

Параметры сети и обучения (mnist_keras.ipynb):

Архитектура: Sequential из трех полносвязных слоев Dense — 784 (ReLU), 200 (ReLU), 10 (softmax).
Функция потерь: categorical_crossentropy; оптимизатор: adam; метрика: accuracy.
Данные: 60000 изображений 28x28 для обучения и 10000 для теста; изображения развернуты в вектор длины 784 и нормированы делением на 255, метки переведены в one hot encoding.
Обучение: 25 эпох, batch_size = 200, validation_split = 0.2, verbose = 2.
Дополнительно: график accuracy/val_accuracy по эпохам, вывод предсказания для выбранного тестового изображения и обработка собственной цифры через OpenCV (перевод в оттенки серого, инверсия, нормировка).

Как запустить: открыть practical-4/mnist_keras.ipynb в Google Colab, выбрать Runtime → Change runtime type → GPU и выполнить ячейки по порядку. Для распознавания собственной цифры нужно смонтировать Google-диск (ячейка с drive.mount), установить opencv-python и scipy и положить изображение размером около 28x28 пикселей по пути /gdrive/My Drive/1/img4.jpg.

Состав папки practical-4: mnist_keras.ipynb (блокнот с программой и заданиями), task.txt (условие).
