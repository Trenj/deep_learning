# deep_learning

Практическая работа 1

Написать компьютерную программу на языке Python 3 создающую и обучающую нейронную сеть для распознавания рукописных цифр с использованием метода градиентного спуска и базы данных MNIST.

Исходные данные:

Количество слоев нейронной сети: 3.
Входные данные для нейронной сети: изображения размером 28x28 пикселов.
Среда программирования: Python 3.6 и выше.
Используемая библиотека: NumPy.
Рабочая ссылка на файл mnist.pkl.gz:

https://figshare.com/articles/dataset/mnist_pkl_gz/13303457?file=25635053

Параметры сети и обучения (папка practical-1, значения по методичке и task.txt):

Архитектура: 784 входа, 30 нейронов скрытого слоя, 10 выходов.
Функция активации: сигмоида.
Функция потерь: квадратичная (среднеквадратичная ошибка).
Обучение: стохастический градиентный спуск, 30 эпох, мини-пакет 10, скорость обучения 3.0.
Данные: 50000 пар для обучения, 10000 для проверки, 10000 для теста. Входы нормированы к диапазону от 0 до 1. Метки обучения закодированы вектором длины 10.

Как запустить (из папки practical-1):

python3 -c "import mnist_loader; training_data, validation_data, test_data = mnist_loader.load_data_wrapper(); import network; net = network.Network([784, 30, 10]); net.SGD(training_data, 30, 10, 3.0, test_data=test_data)"

После каждой эпохи выводится точность на тестовой выборке в виде Epoch N: верно / 10000.

Результат контрольного запуска за 30 эпох: на нулевой эпохе 9022 из 10000, лучший результат 9488 из 10000 на эпохе 26, на последней эпохе 29 получено 9477 из 10000. Точные числа зависят от случайной инициализации весов и могут отличаться при повторном запуске.

Состав папки practical-1: network.py (сеть и обучение), mnist_loader.py (загрузка MNIST), mnist.pkl.gz (данные), task.txt (команда запуска), report.pdf (отчет со скриншотом).
